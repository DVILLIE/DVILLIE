D'Vielle watches the Windows PC it is installed on, explains what it noticed in plain language, and changes nothing until you choose. It is local-first, open source under MIT, and works alongside Microsoft Defender rather than replacing it.

## D'Vielle 2.5.0

**[Release notes and download](https://github.com/DVILLIE/VIGILLANCE/releases/tag/v2.5.0)** &middot; [Changelog](https://github.com/DVILLIE/VIGILLANCE/blob/main/CHANGELOG.md) &middot; [Repository](https://github.com/DVILLIE/VIGILLANCE)

- **Nexus Fold Prime theme**: pearl folded overview, cobalt network stage and bottom dock, in Dark and Light, with motion you can turn off.
- **Quantum Key logo**: a cube-circuit mark with silent electrical surges.
- **Assessment engine and Quantum readiness**: consent-based local assessment of processes, signatures, dependencies, certificates and TLS, with a post-quantum readiness view.
- **Scoped protection helper**: an optional LocalSystem service limited to one approved, per-app network restriction. The monitor itself stays at normal user rights.
- **Undoable protection**: journalled firewall, ASR and Controlled Folder Access changes with rollback.
- **Hardened core**: sandbox launch checks, threat-intel fixes, offline-update recovery, protected Python 3.14 runtime, Program Files install.

## What it watches

| Pillar | What you get |
|--------|--------------|
| Speed | What is slowing the PC, with safe options |
| Storage | Disk pressure and approved temp cleanup |
| Privacy | Telemetry and data-leaving settings Windows exposes |
| AI data leaving | Apps quietly sending data off the machine |
| Camera | Camera-use awareness, within what Windows allows |
| Online footprint | Exposure, with clear next steps |
| Protection | Defender and security posture, working with Defender |

Every change needs your choice **and** a second safety check. Unknown readings stay unknown.
