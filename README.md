## Featured project

### [VIGILLANCE](https://github.com/DVILLIE/VIGILLANCE) — DVielle for Windows

A free guardian for Windows 10/11. It watches speed, privacy, and Defender posture on the PC where you install it, then shows options. Dual-gated: your choice + a safety check before anything changes.

**[Download latest release →](https://github.com/DVILLIE/VIGILLANCE/releases/latest)**

## Pillars

1. **Speed** — what’s slowing the PC; safe options to ease load  
2. **Storage** — disk pressure; safe temp cleanup when you approve  
3. **Privacy** — telemetry / data-leaving settings Windows exposes  
4. **AI data leaving** — apps quietly sending data off-machine  
5. **Camera** — camera-use awareness (honest limits on what Windows allows)  
6. **Online footprint** — surface exposure; solution-oriented paths  
7. **Protection** — Defender / security posture health — works *with* Defender, never replaces it
